| 菜单管理   | `/api/v1/sys/menu/`   | ○ 待开发 |

## Phase 2 — 租户业务面

目标：支持租户管理、App 注册接入、垂直业务配置。

| 模块             | 功能          | 说明                               |
| ---------------- | ------------- | ---------------------------------- |
| 租户管理         | 租户 CRUD     | 创建/编辑/启停/配额设置            |
| App 管理         | 应用注册/配置 | 家庭 App 接入 Kava，配置权限 Scope |
| 垂直业务配置     | 模块开关      | 平台管理员为租户启用/禁用业务模块  |
| Member 管理      | C 端用户      | 会员列表、分组、标签管理           |
| 租户级 Dashboard | 租户视角      | 用量统计、App 概览                 |

---

## Phase 3 — 应用生态

目标：开发第一个垂直 App，跑通全链路。

| 任务                | 说明                               |
| ------------------- | ---------------------------------- |
| 确定第一个 App 方向 | 选择一个垂直领域                   |
| 开发 App 前后端     | 独立于 Admin 的应用                |
| 接入 Kava 后端      | OAuth2 认证、调用 API、Member 管理 |
| 验证全链路          | 从注册到使用的完整流程             |
