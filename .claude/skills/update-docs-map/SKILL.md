扫描 `docs/` 目录并重新生成 `docs/00-project-map.md`。

这是一个 **agent 驱动** 的操作——我会遍历文件系统、读取每个文档的标题和摘要，然后重写索引文件。

**步骤**

1. **扫描 `docs/` 目录结构**

   使用 Bash 的 `find` 命令列出 `docs/` 下所有 `.md` 文件（排除 `00-project-map.md` 自身）。
   按子目录分组。

2. **读取每个文档提取摘要**

   对每个 `.md` 文件：
   - 读取文件的前几行（标题和开头段落）
   - 提取一级标题 (`# Title`) 作为文档名称
   - 提取标题后的第一段或描述行作为说明（一句话，不超过 50 字）
   - 如果文件没有明确的标题或描述，根据文件名和内容推断一个简短说明

3. **生成 `00-project-map.md`**

   按以下格式生成索引：

   ```markdown
   # Docs Project Map

   项目文档目录索引。

   ## <子目录名>/

   | 文档                              | 说明       |
   | --------------------------------- | ---------- |
   | [filename.md](子目录/filename.md) | 一句话说明 |
   ```

   - 顶级 `.md` 文件（不在子目录中）放在最前面，不带子目录标题
   - 子目录按字母排序
   - 每个子目录内的文件按字母排序
   - `00-project-map.md` 自身不列入索引

4. **写入文件**

   将生成的内容写入 `docs/00-project-map.md`，覆盖原有内容。

5. **显示摘要**

   输出变更摘要：

   ```
   ## Docs Map 已更新

   扫描到 X 个文档，分布在 Y 个目录中：

   - 新增: <列出新增的文件>
   - 移除: <列出已不存在的文件>
   - 无变化: 如果没有差异则提示
   ```

**护栏**

- 不修改任何 `docs/` 下的文档内容，只更新索引
- 说明文字保持简洁（一句话），不要复制整段内容
- 如果某个文件读取失败（如权限问题），跳过并在摘要中标注
- 操作是幂等的——多次运行结果一致
